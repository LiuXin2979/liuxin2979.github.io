## 项目概览

这是一个面向齿轮啮合测量工位的 Windows 上位机，使用 C#、WinForms 和 .NET Framework 4.8，运行于 Windows x86。它根据主轴角度、从轴角度和扭矩采样计算间隙曲线，帮助操作人员查看本轮结果并对比历史记录。

## 从采集到结果

1. **选择机型**。读取该机型的测量参数和判定限值。
2. **采集与计算**。记录主从轴角度及扭矩，生成间隙曲线，同时计算最小值、最大值、极差和扭矩波动。
3. **保存与对比**。保存采样数据和结果，支持叠加历史曲线、查看变化趋势和分析重复性。

## 离线回放

程序可使用模拟数据演练，也能导入 TDMS 或 CSV 原始记录重新计算。回放时可以用同一组采样对比计算结果，检查参数或算法调整对曲线和指标的影响。

离线验证覆盖计算和模拟流程。现场运行还需要核对设备通信、采集接线、机型标定和判定限值，验收以现场记录为准。
