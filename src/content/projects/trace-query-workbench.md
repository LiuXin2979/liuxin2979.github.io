## 实验目标

用虚构数据构造一张包含工位、时间和结果的表。预先固定样例数量、工位分布与查询参数，以便重复观察读页、计划和耗时。

## 可以对比什么

- 同一日期筛选使用时间范围与对列执行转换时，返回结果和计划的区别。
- 在固定数据集上，添加候选索引前后的读取量和空间占用。
- 窄范围与宽范围分别使用什么访问路径，以及对写入的影响。

可配合文章 [从逻辑读取量定位 SQL Server 查询瓶颈](/posts/sql-query-diagnostics/) 阅读。
